# USA-STATEWISE-SALES-ANALYSIS

## 📊 Project Overview
This Power BI report analyzes state-level sales performance and return rates across the United States. It incorporates interactive filters and map visualizations to inspect sales by state, order ID, and return status.

## 🔑 Key Features
- *State & Order Level Breakdown:* Tabular view displaying State, Order ID, Sum of Sales, and Returned status.
- *Interactive Slicers:* Filtering capability by Returned status (Yes/No) and State.
- *Geospatial Visualization:* Integrated Map visual providing location-based insights across US states.

## 🛠️ Tools Used
- *Business Intelligence:* Microsoft Power BI Desktop
- *Visuals:* Map Visual, Matrix/Table Visual, Tile Slicers
